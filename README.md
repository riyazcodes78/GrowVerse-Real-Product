# GrowVerse — Real Product Prototype

React + Vite frontend with an Express backend and a founder/admin command center.

## Run locally

```bash
npm install
npm run dev
```

This starts:
- Vite: http://localhost:5173
- Express API: http://localhost:8787

The Vite dev server proxies `/api/*` to the Express API.

## Production build

```bash
npm run build
npm start
```

## Main product areas

- Member Overview
- My Journey
- Discover / opportunity matching
- Community / workshops concept
- Founder OS / command center
- Member attention queue
- Journey momentum visualization
- Live activity signals
- Express API for member actions

Images are loaded from Unsplash during development, so an internet connection is required for the photography.
